# Evaluation repositories

Code used by Kitsune's quality evaluations. Nothing here is part of Kitsune itself.

| Folder | What | Used by |
|---|---|---|
| `shop/`, `notes/`, `ledger/` | Small fixtures written for Kitsune (Python, TypeScript/JS, Go) with known answers | `eval/run_eval.py` |
| `gson/` | Google Gson — Apache License 2.0 | `eval/eval_v2.py gson` |
| `spring_petclinic/` | Spring PetClinic — Apache License 2.0 | `eval/eval_v2.py petclinic` |

## Third-party sources

| Folder | Upstream | Commit |
|---|---|---|
| `gson/` | https://github.com/google/gson | `828cbe0d7c5ab224c9bf441914ee391677196c0f` |
| `spring_petclinic/` | https://github.com/spring-projects/spring-petclinic | `500158f732419217507c7656904b8e6aa1bcc0d6` |

Both are redistributed unmodified under the Apache License 2.0; their `LICENSE` /
`LICENSE.txt` files and source headers are kept. To keep the repository small, these were
removed from the copies: `.git`, CI configuration, build tool wrappers, and build output
(`target/`, `.gradle/`, `.class` files, jars).

One exception: `gson/**/target/generated-*sources/` keeps the 33 Java files generated by
Gson's own Maven build (protobuf test classes). The Gson benchmark was measured with them
in the index, so they stay for reproducibility.
